### Projects

**[radar-dsp-signal-chain](https://github.com/keerthivasan01082004-arch/radar-dsp-signal-chain)**
FFT-based digital spectrum analyzer paired with a pulse-compression radar signal chain, implemented end-to-end in MATLAB.
`MATLAB`

**[miniC-to-MIPS-Compiler](https://github.com/keerthivasan01082004-arch/miniC-to-MIPS-Compiler)**
A compiler front-to-back: translates miniC source into MIPS32 assembly, built with Flex, Bison, CMake, and tested with Catch2.
`C++` `Flex/Bison` `CMake`

**[collaborative-drawing-canvas](https://github.com/keerthivasan01082004-arch/collaborative-drawing-canvas)**
Real-time collaborative drawing canvas — multiple users sketching on the same board, synced live over WebSockets.
`TypeScript` `WebSockets`

**[the_audit_flam_1](https://github.com/keerthivasan01082004-arch/the_audit_flam_1)**
An audit of a flawed tokenizer-fertility and model-capacity analysis: found the bugs, rebuilt the metrics from scratch, and independently verified every number.
`Python`
